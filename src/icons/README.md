# Icons

Duotone icons from [Phosphor](https://phosphoricons.com) (MIT licence, see
`LICENSE-phosphor.txt`), shown with `src/components/Icon.astro`:

```astro
<Icon name="bank" size={28} />
```

To add one: find it on phosphoricons.com, take the **Duotone** weight, and
save the SVG here under its name without the `-duotone` suffix (for example
`rocket-launch.svg`). Keep the file as downloaded: the component sizes and
colours it.
