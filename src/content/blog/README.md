# Articles

Each file in this folder is one article on theaha.co, and its name is the
address: `what-a-bank-should-ask.md` is published at
theaha.co/blog/what-a-bank-should-ask.

To add one, click **Add file**, then **Create new file**, and follow
[Publish an article](../../../docs/CONTENT.md#publish-an-article), starting
from the [article template](../../../docs/templates/article.md).

Covers go in [public/images/covers](../../../public/images/covers/), images
inside an article in [public/images/blog](../../../public/images/blog/).

This file is not an article: the site ignores it.
