# Article covers

One image per article, with exactly the same name as the article file: the
article `what-a-bank-should-ask.md` uses `what-a-bank-should-ask.jpg` (or
`.png`; `.webp` works on the site, but LinkedIn previews may not show it).
There is nothing to write in the article: the page finds the cover by its
name.

Size: 2520 x 1080 px (wide format, 21:9), under 300 KB.

GitHub cannot rename a file while uploading it: rename the image on your
computer first, then click **Add file**, **Upload files**.
